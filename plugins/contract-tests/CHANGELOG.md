# Changelog

## 0.1.0

- The `contract-tests` skill: how to test a client end to end without a person, a client binary or a model call. It covers writing the contract down first, mocking each human or binary step with a protocol speaker, keeping the server real, discovery, one profile per client, failing on hidden spend, proving atomic and idempotent writes, and reporting each item as passed, failing or not checked.
