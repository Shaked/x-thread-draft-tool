# חיבור אפליקציית AI דרך MCP

גרסה באנגלית: [mcp.md](./mcp.md). הקובץ הזה כולל תקציר של מה המחבר עושה, הגדרה לכל לקוח, ניתוק ופתרון תקלות. כלים, כתובות ופקודות נשארים באנגלית.

המחבר של X Thread Draft Tool נמצא בכתובת `https://x-thread-draft-tool.vercel.app/api/mcp`.
אפליקציית AI שתומכת ב-MCP יכולה לקרוא ולשנות את הטיוטות שלכם דרך המחבר. מאשרים את החיבור פעם אחת, בדף ההתחברות, ואפשר לנתק אותו בכל רגע. הטיוטות פרטיות: רק אתם רואים אותן, ומישהו אחר רואה טיוטה רק דרך קישור שיתוף שאתם יוצרים.

המחבר רואה רק מה שאתם רואים באפליקציה. הוא פועל בשמכם, עם אותן טיוטות ואותן מגבלות כמו באפליקציית הווב. פרסום טיוטה באפליקציה מסמן אותה כמפורסמת בלבד, והוא לא מפרסם שום דבר ב-X/טוויטר.

דף האישור מברך אתכם בשם המשתמש שלכם ב-GitHub, ויש בו קישור לקריאה בלבד עם הכפתור Copy link. אפליקציות AI פותחות אותו לעיתים קרובות בדפדפן פנימי. העתיקו את הקישור ופתחו אותו בדפדפן שלכם; פתיחה בדפדפן אחר נתמכת. מי שלא מחובר רואה את הדף "Sign in to continue" עם אותו שדה קישור, לפני GitHub. אם הדף מציג חשבון לא נכון, "Not you? Sign out" מסיים את ההתחברות בדפדפן הזה בלבד, בשרת, ומחזיר לדף ההתחברות. הוא לא מנתק אפליקציות AI או אסימוני API; את זה עושים בדף Connected apps (`/settings/apps`).

## הגדרה

בכל הוראה משתמשים באותה כתובת של המחבר. האפליקציה מבקשת שתתחברו עם GitHub, ואז שתאשרו את הגישה.

הפרטים הבאים נקראו ב-2026-11-12 ולא נבדקו מחדש מול התיעוד של כל לקוח. אם שלב נראה אחרת, בדקו את דף ההגדרות של האפליקציה.

**Claude (web, desktop, mobile)**
1. פתחו את Settings, ואז Connectors, ולחצו על Add custom connector.
2. הדביקו את הכתובת ולחצו על המשך. אשרו בדף ההתחברות.

**Claude Code**
1. הריצו בטרמינל: `claude mcp add --transport http x-thread <URL>`.
2. ב-Claude Code הריצו `/mcp`, בחרו `x-thread` והתאמתו.

**Codex CLI**
1. הריצו: `codex mcp add x-thread --url <URL>`.
2. הריצו `codex mcp login x-thread` ואשרו בדפדפן.

**ChatGPT**
1. הפעילו את Developer mode בהגדרות.
2. צרו connector, הדביקו את הכתובת ובחרו OAuth לאימות.

**Grok**
1. פתחו את `grok.com/connectors` ולחצו על New Connector.
2. בחרו Custom, הדביקו את הכתובת והשלימו את ההתחברות אם הדף מבקש.

לא נבדק: השלבים של Grok לא נקראו מהתיעוד של xAI. הדף https://docs.x.ai/grok/connectors לא נפתח מסביבת הבנייה ב-2026-11-26, ולכן השלבים מבוססים רק על תוצאות חיפוש. בדקו אותם באפליקציית Grok לפני שתסתמכו עליהם. הבדיקה הידנית היא פריט 5 ב-[#430](https://github.com/Shaked/x-thread-draft-tool/issues/430).

## ניתוק

ב-Connected apps (`/settings/apps`) הסירו את האפליקציה. הגישה מתבטלת מיד. כדי לבטל אסימון, השתמשו ב-**Your tokens** באותו דף.

## פתרון תקלות

| מה רואים | הסיבה | מה לעשות |
|---|---|---|
| דף "Invalid redirect URI" | ה-callback של הלקוח לא רשום | דווחו על הלקוח ועל הכתובת בכרטיס היומן (ledger issue) |
| ההתחברות מסיימת בדף הבית | בקשת ההרשאה הייתה ארוכה מ-2,000 תווים | התחילו את החיבור מחדש; אתם מחוברים עכשיו |
| עובד, ואחרי כשעה נכשל | הלקוח לא חידש את הגישה | נתקו והתחברו מחדש; דווחו |
| 403 "Cross-origin request blocked" | הלקוח שלח Origin של דפדפן | דווחו (D-4) |
| 401 "Missing or invalid access token" | אין אסימון, או שהחיבור נותק | התחברו מחדש |
| שגיאת "Rate limit reached" | יותר מ-120 קריאות לכלים בדקה | המתינו דקה ונסו שוב |
