# CI runs the browser tests in three parts

- The browser tests now run as three parallel jobs, so the slowest CI job is shorter and a merge reaches production sooner.

Area: Speed
Link: https://github.com/Shaked/x-thread-draft-tool/issues/470

## Technical details

`.github/workflows/tests.yml`: `e2e-shard` runs `playwright test --shard=N/3`; the job named `E2E tests (playwright)` stays as an aggregate that never skips, so branch protection is unchanged. Artifact names carry the shard number. Guard added to `tests/unit/tests-workflow.test.js`. No limit or test changed.
