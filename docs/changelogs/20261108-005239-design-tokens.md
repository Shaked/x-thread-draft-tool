- Text on accent or danger backgrounds uses `--accent-text`; other `#fff` text uses `--text-strong`.
- Removes 35 top-level CSS rules whose class selectors no component references (checked against `src/` and `index.html`). The file goes from 1,789 to 1,567 lines.
