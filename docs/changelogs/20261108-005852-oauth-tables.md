# OAuth tables

- Adds migration `db/migrations/003_oauth.sql` (additive only): `oauth_clients`, `oauth_grants`, `oauth_codes`, `oauth_tokens`, with the keys, unique constraint, cascading foreign keys and indexes from plan Task 7.3.
- Only hashes of codes and tokens are meant to be stored in these tables. No endpoint reads or writes them yet, so existing behaviour is unchanged.
- New test `tests/api/oauth-migration.test.js` checks that the migration applies on PGlite and is idempotent, that the columns and constraints match the plan, and that the destructive-statement lint passes.
