# MCP views go live on the draft tools (T4, #177)

- `get_draft`, `create_draft`, `split_text` and `create_thread_from_text` now point at the thread view, so Claude and ChatGPT can show it when the host supports MCP Apps. Text and data are unchanged for every client.
- The view's results carry the outline, the editor link and the one image host in `_meta` (`x-thread/outline`, `x-thread/editorBase`, `x-thread/imageOrigin`); the create tools also carry the full posts in `x-thread/posts`, since their structured result has the outline only. Not checked in Claude or ChatGPT.
