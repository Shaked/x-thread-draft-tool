# Security gates: CodeQL, dependency review, audit, gitleaks (plan Tasks 2.1–2.3)

- Adds `.github/workflows/codeql.yml`: CodeQL for JavaScript and TypeScript with `security-extended` queries, on push to `main`, on pull requests and weekly.
- Adds `.github/workflows/security.yml` on pull requests with three jobs: `dependency-review` (fails on high severity), `audit` (`npm audit --audit-level=high`) and `gitleaks` (full history, pinned image digest).
- Adds `.gitleaks.toml`: default rules, plus an allowlist for `tests/` and the fixed test session secret.
- The pre-commit hook scans staged content with gitleaks when it is installed locally; otherwise it prints one line and continues.
- Action versions are pinned to commit SHAs with a version comment. The SHAs come from the release pages' commit links; the tag objects could not be checked from this session.
- Checks run locally: the pinned gitleaks v8.30.1 full-history scan exits 0; a staged fake `ghp_` token makes `gitleaks protect --staged` exit 1 (not committed); a throwaway copy with `lodash@4.17.20` fails `npm audit --audit-level=high`, and the repo passes it.
