# The admin can use admin routes from the browser

- The owner's signed-in browser can now call the admin routes. Everyone else still gets the same "not found" answer.
- Each browser call counts toward the same 120 calls a minute as the AI app admin tools.

Area: Admin
Link: https://github.com/Shaked/x-thread-draft-tool/pull/489
