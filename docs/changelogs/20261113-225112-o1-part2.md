# Draft saves now check for conflicts

- Saving or publishing a whole draft now happens as one step.
- If the draft changed since it was read, the save is refused.
- Repeating a save that already happened changes nothing.
- AI apps can give a new post an ID of their own.
- Repeating an add with the same ID writes nothing, and different text under that ID is refused.

Area: Editor
Link: https://github.com/Shaked/x-thread-draft-tool/pull/102

## Technical details

O1 part 2: whole-draft PATCH and publish run in one transaction on a locked row, honour If-Match (`*`, strong tags, 400 if malformed, 412 with the current version) and are no-ops on replay.
GET and write responses send `ETag: "<version>"`. MCP add_post, remove_post and move_post send the version they read; a conflict is a tool error to re-read. add_post accepts an optional `post_id` (same id and text: no write; other text: 409).
