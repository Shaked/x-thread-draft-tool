# Rare UI toast behind the flag

- With the Components switch on, copy, share and publish messages show as Rare UI toasts; a failure stays until you close it.

Area: Design
Link: https://github.com/Shaked/x-thread-draft-tool/pull/513

## Technical details

Rare UI toast (upstream 0e9f0ef, sonner 2.0.8 pinned as a new dependency, MIT) copied into src/ui/rare/Toast.jsx with its figma-squircle clip, iOS colours and hover-only close removed; the provider in src/ui/Toast.jsx keeps the same toast() API and the 15 call sites, and loads the Rare stack only with xt-kit=rare. Token --toast-inset in tokens.css; lazy chunk only with the flag on.
