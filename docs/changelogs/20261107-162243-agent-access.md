# Agent-first access: API tokens, device flow, discovery, local smoke tests

- Personal API tokens (`xt_...`, hash-only storage, 90-day default), created at `/settings/tokens`.
- GitHub device flow for agents (`/api/auth/device/start` and `/poll`, `npm run agent:login`).
- Parity endpoints: duplicate, export (json/text/formatted), `/api/threads/split`, server-side image fetch with an SSRF guard, `limit` on draft lists.
- Discovery: `/llms.txt` and `/api/openapi.json`, with a parity test against the router.
- Local headless API (`npm run dev:api`) and smoke tests (`npm run smoke`) at local and deployed levels; CI runs the local one.
- Docs: `docs/agents/api.md`, README "API & agents", `AGENTS.md`, `claude.md` pointers.
