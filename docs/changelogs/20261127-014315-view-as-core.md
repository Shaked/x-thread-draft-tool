# The admin can view as a user, read-only (server core)

- The server can now treat the admin's own browser session as another user for reading. Nothing starts it yet (the start button comes in the next tasks).
- While viewing, every change is refused, tokens and apps are closed, and the admin sees draft counts, never draft text.

Area: Admin
Link: https://github.com/Shaked/x-thread-draft-tool/issues/289

## Technical details

`xt_view_as` claim (`server/admin/view-as.js`), applied only in `authenticate` on the cookie path; `assertWritable`; `requirePersonalUser` and `requireSessionUser` refuse it; OAuth authorize answers 409; logout clears both cookies. Draft reads answer through `privateDraft` and `refuseWhenViewing` in `server/routes/drafts.js`.
