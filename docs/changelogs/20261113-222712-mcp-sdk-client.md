# A test uses the official MCP client

- A new test uses the official MCP client library to run the full sign-in and tool flow inside the app.
- It makes no network calls and needs no app, person or AI model.

Area: Docs
Link: https://github.com/Shaked/x-thread-draft-tool/pull/101

## Technical details

Add `tests/api/mcp-sdk-client.test.js`: the official MCP TypeScript SDK client (1.32.2, exact devDependency) runs discovery, registration (DCR and client metadata document), scripted consent, token, initialize, tools/list, tools/call and refresh against the in-process router.
No network, client app, person or LLM.
