# Four ready-made prompts for AI apps

- AI apps get four slash commands: make a thread from notes, tighten a draft, review before publishing, and rewrite a hook.
- Each has an English and a Hebrew description.

Area: AI apps
Link: https://github.com/Shaked/x-thread-draft-tool/pull/107

## Technical details

MCP prompts (plan Task 14): four slash commands (`thread_from_notes`, `tighten_draft`, `review_before_publish`, `rewrite_hook`) with bilingual descriptions; capabilities now `{ tools: {}, prompts: {} }`.
Adds `server/mcp/prompts.js`, `prompts/list` and `prompts/get`, tests, a "Slash commands" docs section and a shared schema test helper.
