# CI identity: GitHub OIDC for the image upload UI test

- Adds server/oidc-ci.js: verifies GitHub Actions OIDC tokens (RS256, claims pinned to this repo and workflow, 5 min). Off unless CI_OIDC_ENABLED=1.
- CI tokens work only on routes marked ci: true (drafts, images, /auth/me, thread split).
- The image upload UI test and workflow use the OIDC token. No stored session secret.
