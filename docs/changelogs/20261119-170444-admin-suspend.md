# Admin suspend and unsuspend (A8, #196)
- The owner's MCP connection can suspend a user (`admin_suspend_user`) and restore them (`admin_unsuspend_user`). A suspended user's sign-ins, tokens, connected apps and share links stop working at once; nothing is deleted.
- The owner must type the user's exact login; the admin account and the CI identity can never be suspended. At most 30 suspend or unsuspend actions per hour.
