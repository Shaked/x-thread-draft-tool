# Admin tools: hidden from everyone but the admin (A3, #183)

- New server/mcp/admin-tools.js holds the admin tools (first one: admin_status). They appear in tools/list and run only for the elevated admin MCP connection; for everyone else an admin tool name is the same unknown-tool error as a made-up name.
- A normal tool runs as a caller with no admin rights, so no /admin route answers it. An admin tool runs as the admin caller naming that one tool (the guard checks the name).
- Admin tool calls are counted once in the same per-minute row as normal calls (120 a minute). The normal budget is unchanged.
- Tests: tests/api/admin-mcp.test.js, tests/api/admin-silence.test.js; the MCP coverage test now lists the admin routes instead of excluding them.
