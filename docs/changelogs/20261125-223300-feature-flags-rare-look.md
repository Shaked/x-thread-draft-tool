# Try a new look from Feature flags

- A new Feature flags page in the menu lets you switch every page to the Rare UI look (orange accent, tighter corners).
- The choice stays on this device only, so you can compare both looks and decide.
- Light, dark and Hebrew right-to-left work in both looks.
