# The admin can suspend, unsuspend and delete a user from the page

- The user page in Admin has buttons to suspend, unsuspend and delete a user.
- Each button opens a box that names the user and what will happen. The admin types the user's login to confirm.
- Delete first shows what will be removed, then asks for the login again.
- Messages from the server are shown as they are.
