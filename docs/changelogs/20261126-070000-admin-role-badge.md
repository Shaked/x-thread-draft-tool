# The owner sees an Admin badge in the app

- When the owner is signed in, the app shows a small "Admin" badge next to the menu button and an Admin section in the menu. Everyone else sees neither.

Area: Admin
Link: https://github.com/Shaked/x-thread-draft-tool/issues/282

## Technical details

Admin hub task #282 (story #482). `GET /api/auth/me` adds `user.role` (`admin` or `user`) for a browser session only, from `roleOf` (`server/admin/role.js`). `AppMenu.jsx` shows the badge and an empty Admin section only for `role === 'admin'`. Files: `server/routes/auth.js`, `server/openapi.js`, `src/components/AppMenu.jsx`, `tests/api/admin-role-arch.test.js` (importer allow-list: `server/routes/auth.js`), `tests/api/auth.test.js`, `tests/unit/AppMenu.test.jsx`, `docs/architecture/capabilities.md`, `docs/features/platform-and-auth.md`, `docs/operations/admin.md`.
