# Admin guard: one check, closed /api/admin prefix, 404 for everyone else (A2, #175)

- server/admin/guard.js is the only admin check (requireAdmin, adminRoute). Only an elevated MCP caller running an admin_ tool with an admin GitHub id passes; everyone else gets the same 404 as an unknown path. The router checks /admin paths before the 405 and CI-token answers.
- The only admin route is GET /api/admin/status (test-only caller until A3/A4 add the tools and the pairing). The admin ids are pinned in server/admin/identity.js (github id 960015).
- The OAuth lookups (REST and MCP) also return the grant's resource and an admin flag: no new query. A REST token never gets admin.
- Smoke: a new step checks that /api/admin/* answers 404 like an unknown path.
