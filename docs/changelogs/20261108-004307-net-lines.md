# Net-lines rule (plan Task 3.5)

- Adds `scripts/net-lines.mjs`: counts added and removed lines in `src/`, `server/`, `api/` and `scripts/` between `origin/main` and `HEAD`. Tests, `docs/` and lockfiles are not counted. Passes when added lines are at most removed lines, or when the pull request body references a plan task (`docs/plans/<name>.md ... Task N`). Prints both counts and the reason.
- Adds `.github/workflows/net-lines.yml` on `pull_request`. The PR body reaches the script only through the `PR_BODY` environment variable.
- Adds `tests/unit/net-lines.test.js` (counting, exclusions, plan-reference exemption, reason).
