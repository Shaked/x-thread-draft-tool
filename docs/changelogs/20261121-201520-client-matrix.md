# Client and language matrix (#365, C1)

- New `docs/architecture/client-matrix.md`: every feature an AI app sees, per client (Claude, ChatGPT, Grok, Claude Code, Codex, others) and per language (English, Hebrew). `tests/api/client-matrix.test.js` fails on a missing cell, a claim `clients.json` does not back, or English text without Hebrew.
- The discovery test scores each client in the mode its `clients.json` profile gives, and a new format eval checks for code fences, unchanged Hebrew and length limits per client.
- PR template with a client-facing checklist; Codex CLI added to `clients.json`.
