# Rare UI is the default

- Rare UI is now the look and the components for everyone, on every page; the admin keeps an off switch on /admin/flags.

Area: Design
Link: https://github.com/Shaked/x-thread-draft-tool/pull/563

## Technical details

Owner decision of 2026-11-26 on #406. `src/utils/skin.js` and `server/admin/flags.js` list `rare` first, so it is the default; a non-admin always reads `rare`.
`index.html` paints Rare UI unless this device last saw the admin with the look switched off, so the sign-in screen and shared pages are Rare UI before any script runs.
The admin's Look and Components switches on /admin/flags are now an off switch ("Old look, purple (only you)"). Tests of the old controls use `tests/unit/helpers/useOldLook.js`.
