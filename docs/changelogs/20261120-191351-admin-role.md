# Admin role in one module
- `server/admin/role.js` decides the role (`roleOf`, `mcpAdminReason`); the guard, the MCP list and the consent note call it.
- New architecture test (`tests/api/admin-role-arch.test.js`) fails if another module reads the admin id or decides admin.
- The admin_status text no longer says "until when"; the silence test now scans the UI resources.
