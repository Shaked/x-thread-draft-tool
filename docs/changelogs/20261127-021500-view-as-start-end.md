# Admin can start and end "view as a user" (website only)

- An admin can now start viewing the app as one user for 30 minutes, with a written reason, and end it at any time. Every start, refusal and end is in the audit log.
- Ending works at once, and at most 30 starts are allowed per hour. AI apps have no tool for this.

Area: Admin
Link: https://github.com/Shaked/x-thread-draft-tool/issues/290

## Technical details

`POST` and `DELETE /api/admin/view-as` (`server/routes/admin.js`); `recordAdminAction` returns the row id, used as the claim's `vid`; `stateOf` in `server/session.js` drops the target when a `view_as_end` row exists for the `vid`; `/api/auth/me` adds `view_as`, `actor` and the real `role`.
