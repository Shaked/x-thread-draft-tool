# F3: nosniff on OAuth pages

- The OAuth HTML pages (consent, sign-in, errors) and the OAuth JSON answers (metadata, registration, token errors) now send `x-content-type-options: nosniff`.
- One shared place: `NOSNIFF` in `server/oauth/consent.js`, and `oauthJson` in `server/routes/oauth.js`. The smoke check for the approval page also checks the header.
