# Theme review fixes (PR #45)

- Overlay controls keep a light foreground in both themes. The light and dark token blocks define `--on-overlay: #ffffff`, and the carousel prev/next buttons and `.remove-image-btn` use it. Before, they used `--text-strong`, which is dark (`#0f1419`) in light theme, over the near-black overlay.
- "Match device" follows OS changes. `src/utils/theme.js` attaches a `prefers-color-scheme: dark` change listener while the choice is `system` and removes it for any other choice. On change it updates the color-scheme and theme-color meta tags and dispatches a `xt-theme-change` event on `window`.
- `src/components/TweetEmbed.jsx` listens for `xt-theme-change` and bumps a state key that the embed effect depends on, so rendered tweets re-embed in the new theme.
- Tests: `tests/unit/theme.test.js` covers the meta tag update and event on a device change, and that a non-system choice registers no listener (and leaving system removes it).
