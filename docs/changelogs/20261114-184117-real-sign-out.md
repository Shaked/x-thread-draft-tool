- Sign out now ends the browser session on the server (a new `revoked_sessions` table, migration 008), not only the cookie. Everyone signs in once more after this ships.
- Sign out also removes the drafts cached in this browser (IndexedDB `draft-*`).
- The OAuth approval page has "Not you? Sign out" (`POST /api/oauth/logout`), which returns to the sign-in page for the same request.
- Cookie requests cost one more query (the revocation check); `tests/api/query-budget.test.js` cookie rows go from 1 to 2 and from 4 to 5.
