# ESLint gate (plan Task 3.1)

- Adds `eslint.config.js` (flat config, ESLint 9): `@eslint/js` recommended for all JavaScript, React and hooks recommended for `src/` and `tests/unit/`, Node globals for `server/`, `api/`, `scripts/`, vitest globals for `tests/`. Rules: `no-unused-vars` (args after-used, `^_` ignored), `complexity` 20, `eqeqeq`, and `no-console` (only `error` and `warn`) for `server/` and `api/`.
- `npm run lint` now runs `eslint .` (it used to run a production build, which is now a separate step in `precommit:checks`). CI's unit job runs `npm run lint` after the build.
- Fixes: removes unused variables and an unused import; `server/oidc-ci.js` and `server/remote-image.js` split into smaller functions with the same checks and log lines; `scripts/migrate-from-supabase.mjs` split into per-phase functions; `DraftEditor` and `PostBox` split into smaller components; `TweetEmbed` derives its invalid-URL error instead of setting state in an effect; `PostBox` derives the clamped image index instead of storing it.
- Deliberate exceptions, each listed in the PR:
  - `react/prop-types` is off: the app does not use PropTypes, and typing components is outside this gate.
  - Four `react-hooks/set-state-in-effect` disables, each with the reason on the same line: the loaders in `DraftList`, `DraftEditor` and `TokensPage` reset the spinner when their inputs change, and `PostBox` sets the embed visible when `IntersectionObserver` is missing.
