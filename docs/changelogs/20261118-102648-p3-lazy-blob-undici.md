## Technical details

# Load the image SDKs only on image routes

- The Vercel Blob SDK and undici now load on first use, not when the API starts, so routes that do not handle images start faster (plan `performance.md` P3). Import time of `api/handler.js` fell from 145-288 ms to 86-105 ms on the same machine. The address checks for remote images are unchanged.
