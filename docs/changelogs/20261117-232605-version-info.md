# The server reports its version

- A public version address and the app version tool for AI apps now return the commit, the deploy time and the database schema version.
- The server version now includes the commit.

Area: Admin
Link: https://github.com/Shaked/x-thread-draft-tool/pull/137

## Technical details

- V1: the server now reports its version. `GET /api/version` (public) and the MCP tool `app_version` return commit, deploy time and database schema.
- The build writes one gitignored file, `server/generated/build-info.js`, read by the client, REST and MCP. `vercel.json` build command no longer sets `VITE_` variables.
- MCP `serverInfo.version` is now `0.1.0+<commit>`.
