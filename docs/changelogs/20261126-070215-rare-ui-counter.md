# Rare UI counter behind the flag

- With the Components switch on, the post character count rolls its digits when they change; the text, the limit and the red "(n over)" stay the same.

Area: Design
Link: https://github.com/Shaked/x-thread-draft-tool/pull/501

## Technical details

Rare UI animated-counter (integer path) copied into src/ui/rare/AnimatedCounter.jsx (upstream 0e9f0ef, motion only, no new dependency), wrapper src/ui/Count.jsx used by CharCounter in PostBox. Tokens --counter-line and --mask-counter-fade in tokens.css; digits forced left to right; not a live region. Lazy chunk loads only with xt-kit=rare.
