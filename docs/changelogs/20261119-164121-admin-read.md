# Admin read tools (A7, #195)
- The owner's MCP connection can list users (`admin_list_users`), read one user (`admin_get_user`), see statistics (`admin_stats`) and the admin audit log (`admin_audit_log`). Only the owner sees them; no draft text, tokens or secrets are shown.
- New routes under `/api/admin` (answer 404 to everyone else); MCP rate-limit rows are now kept 8 days (was 1) so the 7-day statistics are correct.
