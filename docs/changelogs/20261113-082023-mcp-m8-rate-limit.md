# AI apps are limited to 120 calls a minute

- Each user can make 120 tool calls a minute through AI apps.
- A call over the limit gets a tool error, not a protocol error.
- Records older than one day are cleared during the regular token cleanup.

Area: AI apps
Link: https://github.com/Shaked/x-thread-draft-tool/pull/88

## Technical details

# MCP M8: tool-call rate limit
- POST /api/mcp allows 120 tools/call per user per minute; the 121st returns a tool error (isError), not a JSON-RPC error.
- New table mcp_rate_limits (migration 004), counted per minute; rows older than one day are deleted with the token cleanup.
