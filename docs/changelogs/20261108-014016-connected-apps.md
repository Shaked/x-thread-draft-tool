# Settings: Connected apps (plan 7.8)

- New `GET /api/grants` lists the caller's OAuth grants (no tokens or hashes); `DELETE /api/grants/:id` revokes one by setting `revoked_at`, and repeating it is harmless.
- Access tokens, refresh tokens and unused codes already check `revoked_at`, so a revoked grant stops working at once.
- Both routes accept a browser session or personal `xt_` token; an OAuth access token gets 403. OpenAPI documents them.
- Settings shows a "Connected apps" section above API tokens (tokens section unchanged). Tests: `tests/api/grants.test.js`.
