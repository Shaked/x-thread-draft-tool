# Settings: Connected apps (plan 7.8)

- New `GET /api/grants` lists the signed-in user's OAuth grants (client name, kind, redirect host, resource, scope, created, last used, revoked). Only the caller's grants are returned; tokens and hashes never are.
- New `DELETE /api/grants/:id` revokes one grant. Revoking sets `revoked_at` on the grant, which access tokens, refresh tokens and unused authorization codes already check, so they stop working at once. Repeating it is harmless.
- Both routes accept a browser session or a personal `xt_` token. An OAuth access token gets 403, as on the personal token routes.
- The settings page has a "Connected apps" section above the existing API tokens section. The tokens section is unchanged.
- OpenAPI documents both routes and a `Grant` schema.
- Tests: `tests/api/grants.test.js`.
