# The admin sees a "Viewing as" bar

- While the admin views the app as a user, a bar on every page names that user and says when it ends, with a Cancel button.
- Cancel and the end time both reload the page, so nothing of that user stays in the browser.
- The user page in the admin area has a View as button that asks for a reason.
- While viewing, buttons that create, change or share things are off, and each says why.

Area: Admin
Link: https://github.com/Shaked/x-thread-draft-tool/pull/592

## Technical details

#291: `src/components/ViewAsBar.jsx`, `ViewAsContext` in `src/utils/viewAs.js`, a sticky `Banner`, `disabledReason` on the controls, and no `idbSet` or autosave in the editor while viewing.
