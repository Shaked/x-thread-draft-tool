The admin sees a fixed "Viewing as <login> · read-only · ends <time>" bar on every page while viewing a user, with Cancel (#291).
Cancel and the expiry timer end viewing and reload the page, so none of the user's data stays in the browser.
The user page has a "View as" button that asks for a reason. While viewing, create, duplicate, delete, share, export, publish, image and token controls are disabled with a reason, and the editor writes nothing to this browser.
