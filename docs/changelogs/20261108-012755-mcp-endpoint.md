# MCP endpoint `/api/mcp` (plan 7.6)

- `POST /api/mcp` takes one JSON-RPC 2.0 message per request (Streamable HTTP, stateless, JSON responses only). `GET` and `DELETE` return 405. Batches and malformed JSON get `-32600` and `-32700`.
- Auth: only `Bearer xta_...` tokens bound to `<origin>/api/mcp` are accepted. A missing, wrong or REST-bound token gets 401 with `WWW-Authenticate: Bearer resource_metadata="<origin>/.well-known/oauth-protected-resource/api/mcp", scope="drafts"`. `xt_` tokens, CI tokens and the session cookie are refused. A foreign `Origin` gets 403.
- Methods: `server/discover`, `initialize` (legacy handshake for 2025-11-25 and 2025-06-18 clients), `notifications/*` (202), `ping` (legacy only), `tools/list`, `tools/call`. Unknown methods get `-32601` (404 on the 2026-07-28 revision).
- Revision 2026-07-28: `MCP-Protocol-Version` is required on every request (except `initialize`); `params._meta` and the `Mcp-Method` and `Mcp-Name` headers must match the body (`-32020` HeaderMismatch); results carry `resultType: "complete"`; `tools/list` carries `ttlMs` and `cacheScope`.
- Tools (11): `list_drafts`, `get_draft`, `create_draft`, `update_draft`, `duplicate_draft`, `export_draft`, `split_text`, `create_share_link`, `add_image_from_url`, `publish_draft`, `delete_draft`. Each calls the existing REST handler in-process as the token's user (`server/caller-context.js`, `session.authenticate` returns the set caller first). `get_draft` and `export_draft` return 404 for drafts the caller does not own. Bad arguments and REST errors come back as `isError: true` results.
- Router: `POST /mcp` is registered with `selfAuth`, so the generic CI-token refusal does not replace the MCP 401. `server/openapi.js` documents the route (the parity test requires it).
- Tests: `tests/api/mcp.test.js` (24 tests) covers the 401 header, REST-bound and `xt_` token refusal, cookie refusal, Origin 403, transport errors, version and header checks, `initialize`, `server/discover`, `tools/list`, and the create, read, list, update, duplicate, split, share and delete tools, including user isolation.
