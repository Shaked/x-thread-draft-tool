# Admin activation with the pairing code (A5, #190)

- A new MCP tool, admin_activate, takes the pairing code the approval page showed and turns admin on for that connection for 24 hours. Three wrong codes cancel the code; a pending connection sees only this tool.
- Admin tools now show for an elevated connection only; the Connected apps list shows "Admin tools until" or "waiting for the pairing code".
- Tests: tests/api/admin-elevation.test.js (activation flow), admin-guard.test.js (pending route), admin-mcp.test.js (activation tool).
