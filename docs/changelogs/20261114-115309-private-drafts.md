# Drafts are readable only by their owner

- Opening a draft that belongs to someone else now shows Draft not found.
- Opening or exporting a draft without signing in is refused.
- The editor shows a sign-in prompt when you are signed out, and never shows a cached copy.
- The Share button is hidden until share links get an expiry.

Area: Security
Link: https://github.com/Shaked/x-thread-draft-tool/pull/113

## Technical details

# Private drafts (T1)

- GET /api/drafts/:id and /export are owner only: another user gets 404, no session or token gets 401.
- The editor shows a sign-in prompt on 401 and "Draft not found" on 404, and never shows a cached copy.
- Share button hidden until T2 (its component is removed); smoke and API tests cover the signed-out refusal.
