# One post can change without resending the thread

- Changing one post's text now saves only that post.
- A repeat of the same change writes nothing new.
- If the draft changed since it was read, the change is refused.
- If a save fails partway, its changes are undone.
- Each draft keeps a version number that goes up with every change.

Area: Editor

# O1: one post changes in one transaction, with If-Match
- New PATCH /api/drafts/:id/posts/:postId changes only one post's text inside one transaction on a locked draft row. Replays write nothing (200), stale If-Match is 412, and a failure rolls back. update_post now makes this one call. Migration 005 adds drafts.version, bumped by every write.
