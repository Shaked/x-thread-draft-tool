# AI apps can change one post

- AI apps can add, change, remove or move one post without resending the rest of the thread.
- Published drafts cannot be changed this way.

Area: AI apps
Link: https://github.com/Shaked/x-thread-draft-tool/pull/85

## Technical details

- MCP M5: add_post, update_post, remove_post and move_post tools change one post without resending the others; published drafts are refused; the server instructions name the post tools.
- Why: an agent had to resend the whole posts array to change one post and could lose images. Plan: docs/plans/mcp-clients.md (step M5).
