# A janitor report for the task list

- Agents can now list duplicate, finished, stale and out-of-order tasks in one short report.
- The report changes nothing by itself; agents apply only the safe fixes.

Area: Docs
Link: https://github.com/Shaked/x-thread-draft-tool/pull/462

## Technical details

`scripts/janitor.mjs` (read-only, gh search only, no model) with fixture tests in `tests/unit/janitor.test.js`, and the
`.claude/skills/task-janitor/SKILL.md` skill with the rules for acting on the report and the phase 2 design.
