# The task list is checked for problems every week

- A weekly check now looks for duplicate, finished-but-open and stale tasks, and posts what it finds.
- It only writes one comment on the reports issue. It closes and changes nothing.
- No change for people using the app.

## Technical details

`.github/workflows/janitor-weekly.yml` runs janitor pass 1 on Mondays (read-only, linted, minimal permissions). Off switch: repository variable `JANITOR_AUTO=off`. Test: `tests/unit/janitor-weekly-workflow.test.js`.
