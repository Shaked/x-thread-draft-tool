# Checks finish faster on every change

- The browser tests now run in four parts instead of three, so a change gets its green check sooner.

Area: Speed
Link: https://github.com/Shaked/x-thread-draft-tool/pull/631
Screenshot: not needed, CI only

## Technical details
Fixes #576. `tests.yml` `e2e-shard` matrix is 1 to 4 (`--shard=n/4`); the required check `E2E tests (playwright)` keeps its name and still fails unless every shard passed. Shard 3/3 ran 57 s of tests before 2026-11-27 16:16 UTC and 69 s after, and set the pace of the Tests run. The UI audit is registered from two spec files (`audit-early.spec.ts` for the first 13 pages of MIGRATED, `ui-audit.spec.ts` for the rest and the component cases, shared code in `ui-audit-cases.ts`): same tests (170 with the view-as-editor page from main), assertions and screenshots, but Playwright shards by test count in file order, so the slow audit tests now spread over the four shards. The index 13 drifts as pages are added; move it in both files. No limit, test or gate changed.
