# Older AI apps can connect now

- A request with no version header is handled as the older protocol version, 2025-03-26, instead of being refused.
- The log now records the other site when a request from it is refused.

Area: AI apps
Link: https://github.com/Shaked/x-thread-draft-tool/pull/82

## Technical details

- MCP M2: a request without MCP-Protocol-Version is handled as 2025-03-26 (legacy) instead of refused; 2025-03-26 is a supported version; a refused cross-origin request logs its host.
- Why: clients on older revisions send no version header. Plan: docs/plans/mcp-clients.md (step M2).
