# Changelog File Strategy

To reduce merge conflicts, create changelog entries as one-file-per-change using:

`YYYYMMDD-HHMMSS-<slug>.md` (UTC)

Example:
- `20260504-074500-docs-skills-refresh.md`

## Rules
- Never append unrelated updates into a shared rolling file.
- Create a new file for each task/PR.
- Keep entries short and link to the relevant docs updated.
