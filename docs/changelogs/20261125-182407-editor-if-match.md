# The editor saves with its version and stops on a conflict

- The editor sends the draft version it loaded as `If-Match` on every save. A save from another app that changed the draft first shows a banner ("Show their changes" or "Keep mine"); nothing is overwritten silently.
- An untouched draft makes no save, including when the page closes.
