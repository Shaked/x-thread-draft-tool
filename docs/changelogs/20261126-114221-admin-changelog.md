# The changelog moves into the admin area

- The admin finds the changelog in the admin area, next to the statistics.
- The old changelog address opens the new page for the admin. Everyone else sees the same page as for any unknown address.

Area: Admin
Link: https://github.com/Shaked/x-thread-draft-tool/pull/527

## Technical details

Admin shell entry and route in `src/pages/admin/AdminLayout.jsx`; `/changelog` redirect in `src/App.jsx`; `/admin/changelog` links in `src/components/AppMenu.jsx` and `src/pages/AboutPage.jsx`.
