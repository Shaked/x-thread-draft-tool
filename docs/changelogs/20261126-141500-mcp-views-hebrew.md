# The thread, drafts and share views speak Hebrew

- Labels and buttons in the three views in Claude and ChatGPT are now in Hebrew for Hebrew users, and the page runs right to left.
- The view uses the host's language when it sends one, else the language of the draft text, else English.
- Post text is shown exactly as written. English stays the default.
