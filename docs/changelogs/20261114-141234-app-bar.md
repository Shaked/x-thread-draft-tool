## Technical details

- One slim app bar on every signed-in page: the draft list, the editor and API tokens. On phones it is a fixed bottom bar, one row, 44 px high.
- Sign-out is a small icon button in the bar. The bar has a hide control; the choice is kept in this browser (`xt-bar`).
- Icons replace the emoji on Share, Agent link, X Thread and Export. The phone bar no longer covers the last post.
- Playwright: `tests/e2e/app-bar.spec.ts` runs in the required job, which now starts the local API and the built app.
