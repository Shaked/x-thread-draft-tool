# Platform and Auth

- PWA support.
- Mobile-responsive UI.
- GitHub OAuth sign-in (`/api/auth/login`, `/api/auth/callback`). Anyone with a GitHub account can sign in.
- Session: signed HS256 cookie `xt_session` (HttpOnly, Secure, SameSite=Lax, 30 days). The GitHub token is not stored.
- Role (#282): `GET /api/auth/me` returns `user.role` (`admin` or `user`) for a browser session, decided by `roleOf` in `server/admin/role.js`. API token callers get no role. The app shows an "Admin" badge next to the menu button and an Admin menu section only for `admin`.
- Owner-only writes are filtered by the session user id in every query; a non-owner gets 404.
- Deployment metadata visibility.
- API tokens page (`/settings/tokens`): create and revoke tokens.
- Feature flags page (`/admin/flags`, admin only since #483; `/settings/flags` and its menu entry are gone): two switches (#406, approved by Shaked 2026-11-25; real components asked for 2026-11-26). They are saved on the admin's own account (`users.ui_flags`, `GET` and `POST /api/admin/flags`, tools `admin_list_flags` and `admin_set_flag`, one audit row `set_flag` per change, no confirm token because only the admin's own view changes) and copied to the device for the first paint. For every other user a stored `xt-skin` or `xt-kit` is ignored: the look and the components are always the default (`allowFlags` in `src/utils/skin.js`). Look: the current purple look or the Rare UI look; it sets `data-skin` on `<html>` from `xt-skin` in localStorage, and `src/styles/tokens.css` overrides tokens only, so every page and `src/ui/` component follows; colour contrast is tested for both looks. Components: the real Rare UI components, copied into `src/ui/rare/` under their licence (MIT with Commons Clause and an attribution clause, `THIRD_PARTY_LICENSES/rare-ui.md`), replace the theme choice in the menu, Delete draft in the list and the post character counter (`xt-kit` in localStorage, read by `src/ui/ThemePicker.jsx`, `src/ui/DeleteButton.jsx` and `src/ui/Count.jsx`). They use Tailwind utilities that take only token values, so they follow the look and the theme. The page links to https://rareui.com as the required credit.
- Connected apps page (`/settings/apps`): "Connect an AI app" lists the four clients with copy buttons; "Connected apps" lists and revokes them.
- Suspension: a suspended account is refused on every sign-in path (cookie, `xt_` and `xta_` tokens, MCP, the OAuth token endpoint, device sign-in, the GitHub callback, the CI identity). The API answers 403 "This account is suspended."; the app shows that notice above the sign-in button (`/?suspended=1`); share links of the account's drafts answer 410 and are not used up. Nothing is deleted, and everything works again after the suspension is lifted.
- Admin area (`/admin`, #285): a lazy chunk (`AdminLayout-*.js`, not precached) that only the admin's browser asks for. A menu (side column from 768 px, a list on phones) with Statistics, Metrics, Feature flags, Changelog, Users and Audit log; Statistics, Metrics (#337: window switch, summary, a requests and p95 line chart in inline SVG, tables by route and tool, a product table), Feature flags (`/admin/flags`, #483) and Changelog (`/admin/changelog`, #484) are built, the others show "Coming soon.". Anyone else is sent to `/`, the same as an unknown path.
- MCP connector at `/api/mcp` (OAuth 2.1 with PKCE, rotating refresh tokens). Setup and tools: [docs/agents/mcp.md](../agents/mcp.md); Hebrew setup: [docs/agents/mcp.he.md](../agents/mcp.he.md).

The MCP connector also offers four slash commands (prompts): `thread_from_notes`, `tighten_draft`, `review_before_publish` and `rewrite_hook`. It serves one skill, `x-thread-drafts` (at `skill://x-thread-drafts/SKILL.md`). Some tools also show a small view inside Claude or ChatGPT: the thread, the drafts list and the share card ([views](../agents/mcp.md#views-in-claude-and-chatgpt)). The labels and buttons of the three views are in English and Hebrew (#371): the view uses the host's locale when the host sends one, else the main script of the draft text, else English; in Hebrew the page is right to left and post text keeps its own direction. Requests may be in Hebrew (עברית), using words such as טיוטה (draft), שרשור (thread) and ציוץ (tweet). X and Twitter (X/טוויטר) are the same service. Publishing a draft in this app posts nothing to X/Twitter.
