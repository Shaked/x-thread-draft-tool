# Sharing and Export

- Drafts are private: only the owner can open or export a draft by id. Other people see a draft only through a share link.
- Shareable read-only draft links.
- One-time X-thread preview links (`/x-thread-preview/<token>`, rendered by `/api/share/<token>?format=html`).
- One-time agent links (`/api/share/<token>.md`). Both links work exactly once.
- Clipboard copy with/without numbering.
- JSON and Markdown exports.
